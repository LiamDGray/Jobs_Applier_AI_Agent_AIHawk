DRAFT — observed on the Sonoran Schools form on 2026-11-11, not yet tested with a dry run.

The form is a multi-step Red Rover application. It starts at the posting's `/apply` page with an email box (`#email-input`) and a "NEXT" button. Use the candidate email; do not sign in with Google, LinkedIn, or another service.

If a "Verify your Email" page appears, read the mailbox for the newest message from Sonoran Schools with a temporary sign-in code, then enter the six-digit code. The code page shows six single-digit boxes; paste the whole code into the first one. If the code does not arrive, use "Resend code" once, then report blocked.

After the code, the pages are:

1. Welcome! — click "NEXT".
2. Resume — upload the resume file. Accepted: `.doc`, `.docx`, `.pdf`, `.txt`; max 20 MB. Click "NEXT".
3. Contact Info — First/Given Name, Last Name/Surname, Phone, Street Address, Address Line 2, City, State/Province/Region, Zip/Postal Code. Click "NEXT".
4. Education — Institution Name, Start Date, End Date (or "Active Enrollment"), Did You Graduate?, GPA, Degree Name. Add another entry if needed. Click "NEXT".
5. Documents — upload proof of degree, certification, and IVP card. Click "NEXT".
6. Review Application — resolve any "issue needs to be resolved" items, then the submit control is "SUBMIT APPLICATION".

There is no references step on this form. Do not look for one, and do not upload reference letters.

After sending: read the page. A confirmation or thank-you page means received. If the Review Application page is still showing, the application was not received; report blocked with the page's message.

Never submit if a required field is empty or if the page is still showing a validation error.
